# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-10-07

### Added
- Multi-platform support (YouTube and Instagram)
- Professional folder structure with organized directories
- Advanced analytics engine with comprehensive reporting
- Main orchestrator for unified bot management
- Interactive CLI menu system
- Scheduled moderation with configurable intervals
- Database logging with SQLite
- Whitelist system for trusted users
- Dry run mode for safe testing
- Comprehensive test suite
- Setup and utility scripts for Windows
- Full documentation in English and Bahasa Indonesia
- Statistics dashboard with multi-day views
- Report generation (daily/weekly) in JSON and text formats

### Changed
- Refactored code into modular structure (src/)
- Improved detection engine with 50+ keywords
- Enhanced error handling and recovery
- Better rate limiting management
- Optimized database operations
- Updated documentation structure

### Removed
- TikTok adapter (not recommended due to lack of official API)
- Old Telegram bot code (deprecated)

## [1.0.0] - 2024-XX-XX

### Added
- Initial release
- Basic spam detection
- Telegram bot functionality
- Simple keyword matching
